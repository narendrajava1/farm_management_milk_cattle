# 🐄 Farm Management, Milk Cattle & Dairy Subscription Platform

Full-stack dairy farm operations and daily milk subscription platform built with **Spring Boot**, **PostgreSQL**, **MongoDB**, **Redis**, **Apache Kafka**, and **React (TypeScript + Tailwind CSS)**, orchestrated via **Docker Compose**.

## Core Capabilities
- **Per-Buffalo Milk Yield Tracking:** Morning/evening liters, Fat %, SNF %, and yield drop alerts.
- **Feed Inventory & Runway:** Real-time stock levels and days-of-feed remaining.
- **Per-Buffalo Daily Maintenance Cost:** Automated feed, labor, vet, utility, and amortization cost per buffalo/day.
- **Live Daily Profit Engine:** Real-time daily net profit (`Revenue - Total Maintenance & Feed Cost`).
- **Customer Milk Subscription Storefront:** Daily/alternate/custom milk plans and dairy products catalog.
